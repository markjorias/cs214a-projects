# CS 214A: Object-Oriented Programming

Java work from the Object-Oriented Programming course (CS 214A, Aug–Oct 2024): small console programs written alongside the lessons. Programs are compiled and run with a plain JDK; no build tool or input files are needed. The course team project, a console warehouse management system, lives in its own repository: **`java-warehouse-management-system`**.

| Project | Description |
|---|---|
| [java-oop-activities](java-oop-activities/README.md) | 14 lab exercises, class activities, assignments and array exercises, from `Hello World!` to arrays, classes and a Swing dialog |

See the project's README for requirements, run commands, the programs with their last-modified dates, and sample output.
